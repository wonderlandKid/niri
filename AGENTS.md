# AGENTS.md

Personal config for the **niri** Wayland compositor (KDL format, see https://kdl.dev). Not a code project — no build/test/lint. Edits take effect because niri live-reloads `config.kdl` on save.

## Validate changes
Always run after editing before considering done:
```
niri validate -c config.kdl
```

## File layout
- `config.kdl` — main config; hand-edited. Ends with `include "dms/*.kdl"` lines.
- `dms/` — files managed by **DMS (DankMaterialShell)**. Most begin with a `DO NOT EDIT / AUTO-GENERATED BY DMS` banner. Do **not** edit these; they are overwritten by DMS. Put custom config in `config.kdl` instead.
  - Hand-editable exceptions (no banner): `binds.kdl`, `colors.kdl`, `outputs.kdl`, `windowrules.kdl` — but they are still DMS-owned and may be regenerated; prefer editing `config.kdl`.
  - `dms/wpblur.kdl` exists but is **not** included from `config.kdl`; adding it is intentional/optional.

## Gotchas
- KDL uses `/-` to comment out a node (not `//`, which is line comments).
- `Mod` = Super on TTY, Alt in a nested winit window.
- DMS is a runtime dependency: binds/startup call `dms ...` (brightness, lock, spotlight). Brightness is hardcoded to backlight device `amdgpu_bl1`.
- Backups `config.kdl.dmsbackup*` / `config.kdl.backup*` are gitignored — do not commit them.
- Actions bound here are also invokable at runtime via `niri msg action <name>`.
